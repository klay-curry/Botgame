### 2.2 randomized 相对 clean 的退化

整体平均下降 **23.5 pt**。按任务类型可以分成两类：

- **抓取 / 倾倒 / 放置类**：退化小，说明动作与物体交互本身较稳。例如
  `stack_bowls_two` −8、`adjust_bottle` −9、`move_stapler_pad` −1、`move_can_pot` −2。
- **依赖视觉定位 / 物体辨认 / 精细对准的任务**：退化大，瓶颈明确在视觉鲁棒性，而不是动作精度。例如
  `move_playingcard_away` −73、`rotate_qrcode` −57、`handover_mic` −52、
  `place_empty_cup` −43、`scan_object` −42、`lift_pot` −42、`dump_bin_bigbin` −41。

两个 setting 都很难的任务：`stack_blocks_three`（4% / 2%）、`lift_pot`（48% / 6%）、
`stamp_seal`（29% / 6%）、`place_mouse_pad`（21% / 7%）、`put_bottles_dustbin`（19% / 8%）。

> 结论：下一轮优先攻视觉侧（随机光照/背景/纹理、物体外观多样性、视觉 token 鲁棒性），
> 继续增加动作侧训练步数的边际收益已经很小。

## 3. 训练配方（等效 10,000 步）

| 项 | 取值 |
|---|---|
| 基座 | `lingbot-vla-v2-6b`（官方发布版，未改模型结构） |
| 数据 | 官方 RoboTwin 2.0 `demo_clean` 50 任务 × 50 条，LeRobot v3.0，14 维关节空间；549,787 帧 |
| 阶段 1 | AMD Radeon 侧按官方 AdamW 配方（global 256、双教师、image augmentation）训到 6600 步 |
| 阶段 2 | 本地 4×GPU，AdamW、lr 5e-5 恒定、warmup 3%、BF16、micro 24 × 4 = global 96，续训 3400 步 |
| 阶段 3 | 从 step 3000 权重补最后 400 步，得到等效 10000 步最终权重 |
| 精度 / 显存 | BF16 训练；4 卡时 `num_workers=8`、`TORCHINDUCTOR_COMPILE_THREADS=8`（否则容器内存易被顶爆） |
| 推理 | BF16，`use_bf16=true`、`use_fp32=false`；48G 卡 2 副本/卡 |

关键转折点是**数据语义对齐**：早期数据缺少与评测环境一致的零位形起步段，导致闭环从 0% 起步；
换成官方 joint_v30 数据（14 维关节空间，episode 第一帧与评测初始状态一致）后，闭环成功率恢复到 50%+。

## 6. 已知限制

1. 自测成绩为 **BF16 推理**；官方复测若使用 FP32，成功率可能有差异。开环 MAE 的 BF16/FP32 差异约 1.9%，闭环差异本轮未单独测量。
2. `demo_randomized` 只做评测，未用于训练，因此泛化 gap（−23.5 pt）仍是下一轮的主要改进空间。
3. 全量评测依赖 6×4090（或同量级多卡）；单卡可复现单任务，但跑完 10,000 局会非常慢。
