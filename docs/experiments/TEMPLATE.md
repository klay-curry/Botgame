## 目标

- 日期：
- 本次要验证的假设：
- 与基线相比唯一主要改动：

## 可复现输入

- 本仓库 commit、LingBot/RoboTwin revision：
- 预训练模型 revision、数据来源与 50×50 clean 审计结果：
- 配置文件、启动命令和环境（GPU/驱动/容器）：
- 随机种子、训练精度、评测精度：

- GPU 数、开始/结束时间、GPU-hours：

- 原始日志位置与 `results.json` 位置：
