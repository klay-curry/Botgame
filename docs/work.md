# 赛题规则原文

1. 任务和主题
本次大赛分为线上初赛和线下决赛两个阶段。

线上初赛由“仿真必做任务”和“真机创新可选任务”组成。仿真任务为所有参赛团队必做内容，作为决赛晋级的主要评审依据；真机 Demo 为可选项，用于体现团队的真实机器人落地能力和工程实践经验。

线下决赛为真机黑客马拉松。晋级决赛的团队将在统一线下空间完成指定真机任务，基于【LingBot-VLA 2.0 预训练模型】完成模型适配、现场调试、真机推理和评测。

赛事指定模型权重（Hugging Face）：https://huggingface.co/robbyant/lingbot-vla-v2-6b/tree/main
赛事指定模型权重（ModelScope）：https://modelscope.cn/models/Robbyant/lingbot-vla-v2-6b
2. 线上初赛任务介绍
2.1 仿真——必做任务
选手需基于 LingBot-VLA 2.0 预训练模型完成训练与调优，训练数据统一使用 RoboTwin 2.0 中 Aloha-AgileX 的 50 个任务 clean 数据，每个任务 50 条，禁止使用 randomized 数据参与训练。

选手可通过调整模型训练参数、优化训练策略、改进数据处理方式、调整模型结构或推理策略提升性能。最终需按照官方评测标准，提交 Aloha-AgileX 50 个任务在 clean 和 randomized 两个 setting 下的测试结果，每个任务测试 100 次。

2.2 真机创新——可选任务
基于 LingBot-VLA 2.0 预训练模型完成一个真实机器人 Demo。真机 Demo 不限制场景、任务、数据和机器人本体，支持单臂、双臂、移动双臂等不同设备形态。

Demo 需体现一定的新颖性、挑战性和真实落地价值，重点考察模型在真实机器人场景中的适配能力、工程实现能力和任务完成效果。禁止人工遥控、剪辑伪造和硬编码演示。真机创新 Demo 作为初赛评审的补充材料，不设置固定分值，主办方将结合 Demo 完成质量作为筛选参考。

2.3 初赛提交方式
初赛作品需在 10 月 26 日 24:00 前完成提交。选手需将所有提交材料打包为一个 Zip 文件，并通过天池平台指定入口提交。提交入口将在天池平台开放，报名后即可看到。

Zip 文件命名建议：团队名称_初赛提交材料.zip

2.6 小红书创作活动提交
参赛选手可将参赛心得、技术分享、调优复盘、真机开发过程或 Demo 等原创内容发布至小红书，并添加话题 #灵波开发者 和 #LingBot。

内容发布后，需将发布账号名称和公开可访问的小红书笔记链接填写在 06_小红书创作活动/xiaohongshu_info.md 中，并与其他初赛材料一并打包提交，用于活动内容统计和人气奖评选。

3. 线下决赛介绍
晋级决赛的团队将在统一线下空间完成真机任务挑战。决赛赛题将在线下决赛开幕当天公布，主办方将为所有参赛选手提供机械臂、数采设备、任务物料、标准预采数据集、边缘推理算力和现场技术支持。

参赛团队需在限定时间内，基于 LingBot-VLA 2.0 完成指定任务的数据采集（按需）、模型适配、现场调试、真机推理。现场将由主办方根据真机推理效果进行打分，作为决赛的最终评奖依据。

线下决赛日程（拟）
以下为赛事流程安排，最终日程以组委会向入围团队发布的赛前通知为准。

Day 1｜签到与环境调试：启动仪式及规则宣讲，选手完成线下签到、设备领取和开发环境检查，熟悉决赛任务、评测规则和提交流程。

Day 2–3｜模型适配与真机评测：团队围绕指定任务完成数据采集、模型训练/微调、真机推理和任务调试，并按赛事规则提交正式评测。第三日下午统一关闭评测及作品提交通道，由组委会完成最终成绩核定、结果公布及颁奖。
